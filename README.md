# Praveen Kumar — Premium Next.js Portfolio

A responsive, editorial-style developer portfolio built with Next.js App Router, React, and Lucide icons.

## Requirements
- Node.js LTS (Node 20.9+ recommended for Next.js 15)
- Internet connection for first install

## Run locally
1. Extract this ZIP.
2. Open the project folder in VS Code (the folder containing `package.json`).
3. Open Terminal → New Terminal.
4. Run:
   ```bash
   npm install
   npm run dev
   ```
5. Visit `http://localhost:3000`.

## Customize
Edit `app/page.jsx`:
- Replace the sample second and third projects with your real projects and links.
- Replace `your.email@example.com` with your professional email.
- Update the LinkedIn URL to your profile.
- Adjust the About section and skills to match your actual experience.

Pro Connect's demo and GitHub links are already filled in from the links provided.

## Build for production
```bash
npm run build
npm start
```

## Deploy
Push to GitHub and import the repository into Vercel. Vercel detects Next.js automatically.
